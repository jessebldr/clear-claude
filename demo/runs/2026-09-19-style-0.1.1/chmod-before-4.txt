`chmod 755` sets a file's permissions to `rwxr-xr-x`:

| Who | Digit | Bits | Meaning |
|---|---|---|---|
| Owner | 7 | `rwx` | read, write, execute |
| Group | 5 | `r-x` | read, execute (no write) |
| Others | 5 | `r-x` | read, execute (no write) |

Each digit is the sum of read (4), write (2), and execute (1). So 7 = 4+2+1, 5 = 4+0+1.

**In practice:** the owner can modify the file; everyone else can read and run it but not change it. It's the standard mode for executable scripts and binaries, and for directories you want others to be able to enter and list (on a directory, the execute bit means "can cd into / traverse").

Common relatives:
- `644` (`rw-r--r--`) — normal non-executable files
- `700` (`rwx------`) — private to owner only
- `777` (`rwxrwxrwx`) — writable by anyone; almost always a mistake

Note that this is a Unix concept — on your Windows setup it applies inside WSL or Git Bash, but NTFS ACLs (via `icacls`) are what actually govern native Windows files.
