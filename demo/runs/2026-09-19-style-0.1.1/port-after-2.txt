```bash
sudo lsof -i :3000
```

Or, if `lsof` isn't installed:

```bash
sudo ss -lptn 'sport = :3000'
```

Both print the PID and process name. `sudo` matters — without it you only see your own processes.

To kill it once you know the PID: `kill <pid>`, or `kill -9 <pid>` if it ignores that.

One-liner if you just want it dead:

```bash
sudo fuser -k 3000/tcp
```
