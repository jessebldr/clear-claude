`chmod 755 file` sets Unix file permissions to **rwxr-xr-x**:

| Who | Digit | Permissions |
|---|---|---|
| Owner | 7 | read + write + execute |
| Group | 5 | read + execute |
| Others | 5 | read + execute |

Each digit is the sum of read (4), write (2), execute (1). So 7 = 4+2+1, 5 = 4+0+1.

**What it means in practice:** the owner can fully modify the file; everyone else can read and run it but not change it. This is the standard mode for executables and scripts, and for directories that everyone should be able to enter and list (on a directory, "execute" means "can cd into / traverse it").

The common sibling is `644` (rw-r--r--) for non-executable files like config or text.
